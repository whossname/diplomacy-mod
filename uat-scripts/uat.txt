Manual replication of ./uat. Run from this directory (uat-scripts/).

Start the scenario (you = team 0, Alice = team 1, Bob = team 2, cheats on):

cd "/home/tyson/.local/state/Beyond All Reason/games/DiplomacyMod.sdd/uat-scripts" && ./game restart

`say N <cmd>` types "/diplo as N <cmd>" for team N (needs cheats). The same commands work typed
in-game as "/diplo <cmd>" for yourself. Gadget/widget edits need ./game restart.

--- Give a unit to an enemy (cheats off; BAR normally blocks this, the mod overrides it)
./say 0 spawn armsolar
./say --raw "/cheat 0"
./say --raw "/diplo count 0 armsolar"        # 1
./say --raw "/diplo shareunit 2 armsolar"    # same share action as the player list
./say --raw "/diplo count 2 armsolar"        # 1 (check quickly: your commander shoots enemy units)
./say --raw "/cheat 1"

--- Partnership (me and Alice)
./say 0 partner 1
./say 1 partner 0          # forms the partnership
./say 0 info
./say 0 vision 1           # expect "vision 0->1: N/N"
./say 0 dissolve
./say 0 info

--- Fealty offer (Alice becomes my vassal)
/diplomacy as 1 fealty 0
/diplomacy as 0 accept 1
/diplomacy as 1 info               # State: Vassal
/diplomacy as 0 allied 1           # expect "allied 0<->1: true/true"

--- Demand (Bob has other units, becomes my vassal)
/diplomacy as 2 spawn armsolar     # x3: gives Bob extra units (cheat hook)
/diplomacy as 0 demand 2
/diplomacy as 2 accept 0
/diplomacy as 2 info               # State: Vassal
/diplomacy as 0 allied 2           # expect "allied 0<->2: true/true"

--- Give a Commander back (cheats OFF, so the engine enforces alliance on transfers)
/diplomacy as --raw "/cheat 0"
/diplomacy as --raw "/diplo sharecmdr 2"   # expect "(Team 2) ... obtained a Commander and is now Independent"
/diplomacy as --raw "/diplo info"

--- Inspecting
./logs                     # diplomacy lines + Lua errors
./logs -a | grep -E "bitter end|taken out|is toast|sunset"   # engine killed a team (should be empty)
./game stop
